# THE BLOOM · 뽑기 (데모 샘플)

아이패드·휴대폰 Safari에서 테스트용으로 공개한 **단일 HTML** 뽑기판입니다.  
보드에 보이는 인스타 아이디는 **합성 데모 샘플**이며, 실제 응모자 명단이 아닙니다.

## 여는 방법

1. 아이패드를 **세로(portrait)** 로 두고 Safari로 이 페이지를 엽니다.
2. **인터넷 연결이 필요합니다** (Three.js CDN).
3. 칸을 탭 → 씨앗 화면 → 씨앗 터치 → 연출 → 닫으면 결과가 칸에 남습니다.

## 결과 저장

- 결과는 **그 브라우저·그 기기**의 `localStorage`에만 저장됩니다.
- 다른 기기, 시크릿 모드, 캐시 삭제 시 결과가 달라지거나 사라질 수 있습니다.
- 서버 동기화·실명단 매칭은 이 데모에 없습니다.

## 관리자 화면

제목 이미지를 길게 누르면 관리자 패널이 열립니다.  
이 저장소는 **클라이언트만** 동작하므로 PIN은 서버 보호가 아닙니다. **샘플·현장 리허설용**으로만 쓰세요. 실서비스 권한 제어에는 쓰지 마세요.

## 기술

- 단일 `index.html` (폰트·타이틀 PNG base64 내장)
- Three.js r147 (jsDelivr CDN)
- GitHub Pages 정적 호스팅
